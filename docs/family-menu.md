# Раздел «Семья»

«Семья» — отдельный раздел текущего пользователя, а не переключение на чужой профиль.
Личные счета, история и персональные копилки остаются в «Моих финансах».

- GET /api/v1/family — участники и только явно общие ресурсы. По умолчанию общих ресурсов нет.
- POST /api/v1/family/invitations — только администратор; одноразовый код на 7 дней.
- POST /api/v1/family/invitations/accept {"token":"..."} — существующий профиль без семьи принимает код. Регистрации и настоящего входа пока нет; выбор пользователя по-прежнему демонстрационный.
- DELETE /api/v1/family/members/{id} — только администратор; исключение из семьи без удаления пользователя, счетов, денег и истории.

Общие ресурсы явно отмечаются таблицами shared_family_accounts/shared_family_pigs.
Связь family_accounts сама по себе не делает личный счёт общим. Интерфейс назначения
общих ресурсов пока не добавлен. Существующие личные записи не переименовываются и не переносятся.

Администратор не удаляет себя. Представитель с оставшимися детьми в семье не удаляется,
пока не отключены дети. Незавершённые запросы удалённого ребёнка отклоняются, резерв сохраняется.
Отметка удаления предотвращает повторное добавление участника demo-seed при перезапуске.
Код приглашения хранится на сервере только в виде SHA256; использованный и истёкший код отклоняется.
Подключение не выдаёт автоматически права списывать с чужих счетов.

Проверки: test_family_api.py — права, приватность, одноразовые/истёкшие приглашения,
сохранность банковских данных и исключения при повторном старте. Полный набор: 121 passed.
