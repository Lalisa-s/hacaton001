# hacaton001

Общий репозиторий MVP детско-семейного банковского приложения.

```text
hacaton001/
├── backend/       # FastAPI, SQLAlchemy, SQLite, тесты
├── frontend/      # uni-app/Vue 3: веб-интерфейс, API-клиент и тесты
├── docs/          # общий контракт, примеры JSON и JSON Schema
├── .gitignore
└── README.md
```

В `backend/` размещён Python-проект, схемы JSON и тесты.
В `frontend/` создано запускаемое uni-app/Vue 3 приложение: счета, перевод в
модальном окне, история, детские копилки и решения родителя.
Общий контракт хранится в `docs/`.

## Живая разработка веб-демо

Из корня проекта в терминале PyCharm (PowerShell):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1
```

Откройте http://localhost:5173. Сохранение Vue/CSS обновляет интерфейс через HMR,
Python в `backend/app` — перезапускает Uvicorn. Данные перечитываются каждые
10 секунд, по кнопке и после финансовых действий. Ctrl+C завершает процессы этого запуска.
Если API уже запущен, используйте `dev.ps1 frontend`.
Подробности, работа с телефона, зависимости и команды двух терминалов:
[frontend/README.md](frontend/README.md).

## Запуск backend

Для демонстрационного API в локальном `backend/.env` включите:

```dotenv
DEMO_MODE=true
DEMO_USER_ID=10
```

По умолчанию демонстрация выключена. Режим не содержит настоящей аутентификации:
используются только вымышленные пользователи и деньги. При первом запуске
создаются отсутствующие таблицы и демонстрационные счета; перезапуск не сбрасывает
остатки и историю.

Команды PowerShell из корня `hacaton001`:

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Локальные адреса:

- Health: <http://127.0.0.1:8000/api/v1/health>
- Swagger UI: <http://127.0.0.1:8000/docs>

После первого клонирования на другом компьютере нужно создать собственное
окружение Python 3.12+, установить `backend/requirements.txt` и создать локальный
`backend/.env` по примеру. Подробная инструкция: [backend/README.md](backend/README.md).

## Совместная работа

Репозиторий Git общий и находится в корне `hacaton001`; в `backend/` и `frontend/`
вложенные репозитории не нужны. Изменения frontend и backend размещаются
в соответствующих папках.

`.gitignore` исключает виртуальные окружения, `.env`, локальные базы данных,
IDE-настройки, `node_modules` и результаты сборки. Файлы `.env.example`
сохраняются в Git как примеры конфигурации.

Для LAN веб-демо используется порт frontend 5173. Откройте
`http://<фактический-IPv4-компьютера-с-frontend>:5173` в той же сети.
Vite проксирует `/api` на локальный backend; для backend на другом компьютере
задайте его адрес в `frontend/.env` (`API_PROXY_TARGET`).

## Обмен JSON с frontend

Действующий контракт и самостоятельные примеры Python/uni-app:
[docs/api-contract.md](docs/api-contract.md).
JSON передаётся в HTTP; файлы примеров используются для согласования и проверок.
Реализованы health, демонстрационные профили, разрешённые счета, переводы
родителя между своими счетами, история и детские копилки: создание, имя,
пополнение участниками семьи, запрос на разбитие и решение назначенного родителя.
На экране есть переключатель «Родитель / Ребёнок / Участник семьи» — это выбор
демо-пользователя через заголовок, а не вход. База и запросы сохраняются в SQLite.
Ребёнок привязан к родительскому счёту явно; обычный `POST /transactions` ему
недоступен, для пополнения копилки используется отдельный маршрут.
Правила и API: [docs/piggy-banks.md](docs/piggy-banks.md).
Задания, учебные функции, питомец и автопереводы пока не реализованы.

Из корня репозитория клиентские проверки запускаются без npm-зависимостей:

```powershell
node .\frontend\tests\test-api.mjs
node .\frontend\tests\test-fixtures.mjs
```
